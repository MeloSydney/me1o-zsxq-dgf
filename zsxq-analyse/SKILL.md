# 知识星球内容分析（浓缩总结）

读取 `zsxq-export` skill 导出的原始数据文件（文件名含 `raw`），对每个帖子进行**浓缩总结**，输出到不含 `raw` 的 markdown 文件。

## 输入参数

`$ARGUMENTS` 格式支持以下两种：

| 格式 | 示例 | 含义 |
|------|------|------|
| 文件路径 | `zsxq_md/0520_大锅饭_raw_2026-05-18_2026-05-20.md` | 直接指定 raw 文件 |
| 日期范围 | `3d` / `7d` / `2026-05-01:2026-05-05` | 自动查找匹配的 raw 文件 |
| 无参数 | 留空 | 自动查找最新的一份 raw 文件 |

### 文件查找规则

- 当输入为日期范围时，先计算 start_date 和 end_date，然后在 `/Users/melo/doc-Dgf/zsxq_md/` 目录下查找文件名匹配 `*raw_{start_date}_{end_date}.md` 的文件
- 当无参数时，查找 `/Users/melo/doc-Dgf/zsxq_md/` 目录下最新的 `*raw*.md` 文件
- 如果找不到匹配的 raw 文件，提示用户：**"未找到对应的原始数据文件，请先使用 /zsxq-export 导出数据"**

## 执行步骤

### 1. 读取 raw 文件

使用 `Read` 工具读取指定的 raw 文件内容。

### 2. 解析帖子结构

从 raw 文件中逐个解析帖子，提取以下信息：
- 能量评分
- 帖子发布时间（含小时:分钟，如 2026-05-20 14:26）
- 帖子原始全文
- 标签
- 附件文件名
- 评论区内容

### 3. 浓缩总结

对每个帖子，基于原始文本进行**浓缩总结**。这是核心步骤，要求：

**总结原则：**

- 用**2-5 句话**概括帖子的核心观点、关键数据和结论
- 保留帖子中的**关键数字**（如营收、增速、市占率、评分、目标价等具体数据）
- 保留帖子中的**核心结论**（如买入/增持评级、板块判断、政策方向等）
- **公司名称和股票代码必须完整保留，不得省略**，并用**加粗**标记（如 **协创数据** **300857.SZ**）
- **公司名称和股票代码加粗标注即可**，无需搜索主营业务
- 如果帖子是提问+回答形式，分别概括**问题要点**和**回答要点**
- 去除免责声明、重复的格式化文本等无关内容
- 评论区只保留**有信息价值的评论**（如补充观点、重要提问），跳过纯表情、纯点赞类评论

**不同帖子类型的总结策略：**

| 帖子类型 | 总结重点 |
|----------|----------|
| 研报精读 | 核心观点 + 关键数据 + 评级/目标价 + 利好公司 |
| 提问回答 | 问题一句话 + 回答核心要点 |
| 观点/闲聊 | 一句话概括主旨 |
| 行业分析 | 核心判断 + 关键逻辑链 + 重点关注方向 |

### 4. 排序

将帖子按以下规则排序（如 raw 文件已排序可保持原序）：

1. **按能量评分降序**（评分高的排前面）
2. **评分相同时，按发布时间降序**（越新的帖子排越前面）

### 5. 生成分析后的 markdown 文件

将总结后的内容写入 markdown 文件：

**文件路径**：将 raw 文件名中的 `_raw_` 去除即可。

- raw 文件：`/Users/melo/doc-Dgf/zsxq_md/{MMDD}_大锅饭_raw_{start_date}_{end_date}.md`
- 分析文件：`/Users/melo/doc-Dgf/zsxq_md/{MMDD}_大锅饭_{start_date}_{end_date}.md`

**排版要求：**
- 总结内容不要写成一段大段落，要**按逻辑分段**，每段 1-2 句话
- 关键数据（营收、增速、评分等）和核心结论用**加粗**标注
- 公司名称和股票代码用**加粗**标注（如 **协创数据**、**300857.SZ**），不得省略
- 公司名称和股票代码直接加粗标注即可，例如：**协创数据**（**300857.SZ**）一季报归母净利润7.50亿元
- 不同主题之间用空行分隔

**文件格式**：

```markdown
# 大锅饭与小伙伴的进步空间

> 来源：https://wx.zsxq.com/group/15522441811252
> 导出时间：{当前日期}
> 日期范围：{start_date} ~ {end_date}

---

## ⭐ {能量评分}分 | {MM-DD HH:MM} | {原始标题}

{帖子浓缩总结，分段排版}

**标签**：{#标签1} {#标签2}

**附件**：{文件名}

---

评论摘要：
{有信息价值的评论摘要}

---
```

**原始标题提取规则：**
- 研报精读类：提取研报主题作为标题（如"磷酸铁锂量价齐升且盈利显著修复"）
- 提问回答类：提取提问者的核心问题作为标题
- 观点/闲聊类：提炼一句话作为标题
- 标题应简洁（15字以内），抓住帖子核心主题

### 6. 输出结果

告知用户：
- 分析后的文件路径
- 原始文件路径
- 总结的帖子数量
- 日期范围

## 注意事项

- 此 skill 依赖 `zsxq-export` 导出的 raw 文件，不直接访问浏览器
- 如果 raw 文件中的帖子内容因页面折叠不完整，总结也会相应不完整
- 能量评分过滤已在 export 阶段完成，此 skill 不再重复过滤
- 此 skill 只做浓缩总结，不修改原始数据
