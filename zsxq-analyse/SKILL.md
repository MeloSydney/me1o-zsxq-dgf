# 知识星球内容分析（全量分类浓缩）

读取 `zsxq-export` 导出的 raw 文件，将**全部抓取数据**互斥地归入以下三个专栏，并逐篇浓缩总结：

1. **🌟 星大派专栏**：星主发布且标题或正文以“星大派”开头的帖子
2. **📝 星主普通专栏**：除星大派外的全部星主帖子，不论有无能量评分
3. **🙋 用户提问专栏**：raw 文件「用户提问」章节中的全部 `q&a` 帖子

不再执行 Top 10 筛选，也不因无评分而丢弃帖子。最终必须满足：

```text
星大派数量 + 星主普通数量 + 用户提问数量 = raw 帖子总数
```

每篇 raw 帖子必须且只能出现在一个专栏中。

## 输入参数

`$ARGUMENTS` 支持：

| 格式 | 示例 | 含义 |
|------|------|------|
| 文件路径 | `zsxq_md/0520_大锅饭_raw_2026-05-18_2026-05-20.md` | 直接指定 raw 文件 |
| 日期范围 | `3d` / `7d` / `2026-05-01:2026-05-05` | 自动查找匹配的 raw 文件 |
| 无参数 | 留空 | 自动查找最新的一份 raw 文件 |

### 文件查找规则

- 日期范围：计算 `start_date` 和 `end_date`，在 `/Users/melo/doc-Dgf/zsxq_md/` 中查找 `*raw_{start_date}_{end_date}.md`
- 无参数：查找 `/Users/melo/doc-Dgf/zsxq_md/` 下最新的 `*raw*.md`
- 找不到时提示：**“未找到对应的原始数据文件，请先使用 /zsxq-export 导出数据”**

## 执行步骤

### 1. 读取并解析 raw 文件

完整读取 raw 文件，解析：

- 星主帖子：标题格式通常为 `## ⭐ {评分或无}分 | {MM-DD HH:MM} | {标题}`
- 用户提问章节：以 `## 🙋 用户提问` 开始，其中每篇提问标题通常为 `### ❓ ⭐ {评分或无}分 | {MM-DD HH:MM} | {标题}`
- 每篇帖子的发布时间、评分、正文、标签、附件和评论
- 用户提问中的提问者、问题正文、回答者及回答正文

不得只解析有评分帖子，也不得忽略 `### ❓` 用户提问子项。

### 2. 按优先级分类

严格按以下优先级分类，保证互斥且完整：

1. **用户提问专栏**
   - raw 中 `## 🙋 用户提问` 章节下的所有 `### ❓` 帖子
   - 即使回答正文以“星大派”开头，仍归为用户提问，不得归入星大派
2. **星大派专栏**
   - 在非 `q&a` 星主帖子中，标题或正文去除评分前缀、Markdown 加粗符号和空白后，以“星大派”开头
   - 包括星大派锐评、星大派每日热点、星大派特刊等
3. **星主普通专栏**
   - 其余所有非 `q&a` 星主帖子
   - 包含研报、行业分析、直播总结、观点和闲聊等
   - **无评分帖子也必须保留**

分类完成后执行覆盖校验：

- 统计 raw 总数 `J`
- 统计星大派 `M`、星主普通 `N`、用户提问 `Q`
- 验证 `M + N + Q = J`
- 检查无重复帖子、无遗漏帖子
- 若不相等，先重新解析并定位遗漏或重复项；不得静默生成不完整分析文件

### 3. 浓缩总结全部帖子

对三个专栏中的**每一篇帖子**进行浓缩，不设置 Top N，不按评分淘汰。

#### 通用总结原则

- 每篇用 **2-5 句话**概括核心观点、关键数据和结论
- 内容较长时按逻辑分成 1-3 个短段落，避免大段堆砌
- 保留并用**粗体**标记关键数字、增速、价格、目标价、评级和核心结论
- **公司名称和股票代码必须完整保留并加粗**，如 **协创数据**（**300857.SZ**）
- 不额外搜索公司主营业务，不添加原文没有的事实
- 删除免责声明、重复格式文本和无信息量内容
- 评论区仅保留有信息价值的补充、澄清或重要追问；跳过表情、点赞和无实质内容的评论
- 原文若截断或缺失，必须明确标注，不得臆测补全

#### 用户提问总结规则

每篇用户提问必须同时覆盖：

- **问题要点**：提问者关心的标的、现象或决策问题
- **回答要点**：星主回答的判断、逻辑、条件和风险提示
- 若尚无回答，写明“截至导出时暂无回答”，不得省略整篇提问
- 若回答中包含评分，保留评分，但用户提问不参与任何筛选

#### 不同内容类型的重点

| 类型 | 总结重点 |
|------|----------|
| 星大派每日热点 | 当日核心事件、关键数据、受益方向与风险 |
| 星大派锐评/特刊 | 核心观点、操作纪律、政策或行业逻辑 |
| 研报精读 | 核心观点、关键数据、评级/目标价、利好公司 |
| 行业分析 | 核心判断、逻辑链、重点关注方向 |
| 直播总结/观点 | 主要结论、操作框架、风险提示 |
| 用户提问 | 问题要点 + 回答要点 + 有价值的追问或补充 |

### 4. 专栏内部排序

- **星大派专栏**：按发布时间降序
- **星主普通专栏**：有评分帖子在前，按评分降序；评分相同按时间降序；无评分帖子排在有评分帖子之后，并按时间降序
- **用户提问专栏**：按发布时间降序

专栏整体顺序固定为：星大派专栏 → 星主普通专栏 → 用户提问专栏。

### 5. 生成分析文件

输出路径为 raw 文件名去除 `_raw_`：

- raw：`/Users/melo/doc-Dgf/zsxq_md/{MMDD}_大锅饭_raw_{start_date}_{end_date}.md`
- 分析：`/Users/melo/doc-Dgf/zsxq_md/{MMDD}_大锅饭_{start_date}_{end_date}.md`

文件结构：

```markdown
# 大锅饭与小伙伴的进步空间

> 来源：https://wx.zsxq.com/group/15522441811252
> 导出时间：{当前日期}
> 日期范围：{start_date} ~ {end_date}
> 星大派专栏：{M} 篇 | 星主普通专栏：{N} 篇 | 用户提问专栏：{Q} 篇 | 合计：{J} 篇

---

## 🌟 星大派专栏

> 全部星大派系列帖子，按时间降序排列

### {MM-DD HH:MM} | {标题}

{2-5句话浓缩总结}

---

## 📝 星主普通专栏

> 全部非星大派星主帖子；有评分帖子优先按评分排列，无评分帖子按时间排列

### ⭐ {评分或无}分 | {MM-DD HH:MM} | {标题}

{2-5句话浓缩总结}

**标签**：{标签，可选}

**附件**：{文件名，可选}

**评论摘要**：{有价值评论，可选}

---

## 🙋 用户提问专栏

> 全部用户提问及星主回答，按时间降序排列

### {MM-DD HH:MM} | {问题标题}

**问题要点**：{问题浓缩}

**回答要点**：{回答浓缩；无回答时明确说明}

**评论摘要**：{有价值评论，可选}

---
```

即使某一类数量为 0，也保留对应专栏标题并写明“本期无此类帖子”，以便读者确认分类已执行。

### 6. 标题规则

- 标题保持简洁，原则上不超过 15 个汉字
- 星大派帖子优先保留“星大派锐评 / 每日热点 / 特刊”等子栏目名
- 研报和行业分析提炼核心主题
- 用户提问提炼问题核心，不使用“某某提问”作为标题
- 不得省略原文中的公司名称或股票代码

### 7. 最终验证与输出

写入后必须验证：

- 三个专栏标题均存在
- 每个 raw 帖子在分析文件中有且仅有一条对应总结
- `M + N + Q = J`
- 三个专栏内部排序符合规则
- 每篇用户提问同时包含问题要点和回答要点，或明确标注暂无回答
- 输出文件存在且非空

告知用户：

- 原始文件路径
- 分析文件路径
- 星大派专栏数量 `M`
- 星主普通专栏数量 `N`，其中有评分/无评分各多少篇
- 用户提问专栏数量 `Q`，其中已回答/未回答各多少篇
- raw 总数 `J` 与覆盖校验结果
- 日期范围

## 注意事项

- 此 skill 依赖 `zsxq-export` 生成的 raw 文件，不直接访问浏览器或 API
- **所有 raw 帖子都必须进入分析结果，不再执行 Top 10 筛选**
- 能量评分只用于星主普通专栏的排序，不用于删除帖子
- 用户提问必须进入用户提问专栏，不得跳过或混入其他专栏
- 星大派帖子必须进入星大派专栏，不得在星主普通专栏重复出现
- 此 skill 只生成浓缩总结，不修改 raw 文件
