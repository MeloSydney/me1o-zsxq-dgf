# 知识星球完整工作流

一键执行「抓取 → 分析」两步流程，输出原始数据文件和浓缩总结文件。**全程通过 zsxq API 抓取，不需要任何浏览器操作。**

## 输入参数

`$ARGUMENTS` 格式：`[日期过滤]`（与 zsxq-export 相同）

| 格式 | 示例 | 含义 |
|------|------|------|
| 单日 | `2026-05-05` | 只导出该日帖子 |
| 日期范围 | `2026-05-01:2026-05-05` | 导出从起始日到结束日的帖子 |
| 相对天数 | `1d` / `3d` / `7d` | 导出最近 N 天的帖子 |
| 无参数 | 留空 | 默认导出最近 3 天 |

## 执行步骤

### 第一步：抓取原始数据（zsxq-export）

按照 `zsxq-export` skill 的完整流程执行：

1. `date +%Y-%m-%d` 获取今天日期，解析日期参数得到 start_date / end_date
2. **删除同日期范围的旧 raw 文件**（每次必须重新拉取，不使用缓存）
3. 执行导出脚本（token 自动从 `.env` 读取）：
   ```bash
   python3 /Users/melo/doc-Dgf/zsxq_export.py --days <N>
   # 或指定范围
   python3 /Users/melo/doc-Dgf/zsxq_export.py --start <start_date> --end <end_date>
   ```
4. 脚本内置规则：
   - 按日期范围过滤
   - **完整保留其他用户提问（`q&a` 类型）帖子，并写入文末独立的「🙋 用户提问」章节**
   - **不做评分阈值过滤，保留所有星主帖子**（评分仅用于排序和展示；用户提问不参与评分过滤）
5. 输出到 `/Users/melo/doc-Dgf/zsxq_md/{MMDD}_大锅饭_raw_{start_date}_{end_date}.md`
6. 验证输出（星主帖子数量、用户提问数量、独立章节及正文完整性）

**此步骤必须完整执行完毕后，再进入第二步。**

### 第二步：浓缩总结（zsxq-analyse）

读取第一步生成的 raw 文件，按照 `zsxq-analyse` skill 的完整流程执行：

1. 读取 raw 文件并解析全部帖子
2. 按互斥优先级分类：
   - **用户提问专栏**：raw 文件「🙋 用户提问」章节下的全部 `q&a` 帖子
   - **星大派专栏**：其余帖子中，正文/标题以「星大派」开头的帖子
   - **星主普通专栏**：剩余所有星主帖子，包括无评分帖子
3. 对三个专栏中的**全部帖子**逐篇浓缩总结，不执行 Top 10 筛选，不因无评分而丢弃
4. 排序：星大派按时间降序；星主普通按评分降序、无评分置后并按时间降序；用户提问按时间降序
5. 验证 `星大派数量 + 星主普通数量 + 用户提问数量 = raw 总数`，并检查无重复、无遗漏
6. 输出到 `/Users/melo/doc-Dgf/zsxq_md/{MMDD}_大锅饭_{start_date}_{end_date}.md`

### 最终输出

告知用户：
- raw 文件路径
- 分析文件路径
- 星大派专栏帖子数量
- 星主普通专栏帖子数量（有评分/无评分）
- 用户提问专栏帖子数量（已回答/未回答）
- raw 总数及三类全量覆盖校验结果
- 日期范围

## 注意事项

- 两步必须顺序执行，第一步完成后再做第二步
- 如果第一步失败（如 token 过期返回 HTTP 401、限流 code 1059），**不执行第二步**，直接提示用户：
  - token 过期：提示更新 `/Users/melo/src-skills/src-zsxq/me1o-zsxq-dgf/zsxq-export/.env`（浏览器 Cookie 中重新获取 `zsxq_access_token`）
  - 限流：等待后重试或稍后再试
- **export 阶段不按评分过滤星主帖子**；用户提问也完整保留到 raw 文件文末独立章节
- analyse 阶段必须总结全部 raw 帖子：星大派、星主普通、用户提问三类互斥且合计等于 raw 总数
- 能量评分只用于星主普通专栏排序，不再用于 Top 10 筛选或删除帖子
- 用户提问按“问题要点 + 回答要点”总结；尚无回答时明确标注，不得跳过
- 星大派帖子永远置顶展示，不得在星主普通专栏重复出现
- 所有细节以 `zsxq-export` 和 `zsxq-analyse` 各自的 skill 说明为准
